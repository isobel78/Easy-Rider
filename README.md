# Easy Rider

I drive a honda moped that is 49cc, so I don't drive on roads over 40mph. Build out a prototype navigation app that allows a user to provide starting and ending locations and map a route that uses only roads less than 40 mph.

This project was built with [Lovable](https://lovable.dev).

**Live app**: https://myeasyrider.lovable.app
